# 💊 Online Medicine Purchase System

A web-based Online Medicine Purchase System built using **Java (JSP & Servlets)** and **Oracle Database**, following the **MVC architecture**.  
The system supports medicine browsing, cart management, order placement, transaction tracking, and admin-side inventory control with OTP-based email authentication.

---

## 🚀 Key Features
- Customer registration & login with OTP email verification
- Medicine browsing, cart handling, and order placement, track delivery
- Stock validation and transaction tracking (Debit / Credit)
- Admin panel for inventory, orders, and transaction monitoring
- SMTP-based automated email notifications
- And many more features to explore

---

## 🛠 Tech Stack
- Java 18 (JSP, Servlets, JDBC)
- Oracle 10g
- HTML, CSS, JavaScript
- Apache Tomcat 9
- JavaMail (SMTP)
- Eclipse

---

## ⚙️ Setup Notes
- A `requirements.txt` file is included with complete setup instructions  
- Required mail and JDBC JARs are available under `WEB-INF/lib/`  
- Follow the requirements file before running the project
